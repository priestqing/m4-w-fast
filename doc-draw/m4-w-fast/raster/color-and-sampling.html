色标与采样 ​

本节由codex施工

颜色模式决定数值如何映射到色标，采样模式决定屏幕像素如何从相邻格点取值。两者彼此独立，可以按数据类型组合。

运行示例 ​

示例使用完整 2510270910.015 数据和完整色标。切换选项后直接更新 GPU 状态，不重新请求数据，也不重新创建地图。

模式对照 ​

配置值效果
colorMode'step'默认模式；数值落入哪个区间，就直接使用该区间颜色
colorMode'smooth'在相邻色标之间连续插值颜色
sampleMode'cell'读取原始格点，格子边界清晰
sampleMode'interpolate'默认模式；对相邻格点做双线性插值，缩放时更平滑

关键代码 ​

vue
<!-- 演示真实栅格在分段/平滑着色与格点/插值采样之间的差异。 -->
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import * as L from 'leaflet'
import 'leaflet/dist/leaflet.css'
import { createRasterLeafletLayer } from 'm4-w-fast/raster-leaflet'
import type { RasterColorMode, RasterLeafletLayer, RasterSampleMode } from 'm4-w-fast/raster-leaflet'
import { loadRasterDemoGrid, rasterDemoColorStops } from './rasterLeafletDemoData'

const mapElement = ref<HTMLDivElement | null>(null)
const colorMode = ref<RasterColorMode>('step')
const sampleMode = ref<RasterSampleMode>('interpolate')
const status = ref('正在加载真实数据')

let map: L.Map | null = null
let rasterLayer: RasterLeafletLayer | null = null
let resizeObserver: ResizeObserver | null = null

const initialize = async () => {
    if (!mapElement.value) return

    try {
        const grid = await loadRasterDemoGrid()
        map = L.map(mapElement.value, {
            center: [30.6, 102.4],
            zoom: 7,
        })
        L.tileLayer('https://webrd0{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}', {
            subdomains: ['1', '2', '3', '4'],
            maxZoom: 18,
        }).addTo(map)

        rasterLayer = createRasterLeafletLayer({
            rendererType: 'webgl2',
            grid,
            colorStops: rasterDemoColorStops,
            colorRange: { minValue: -72, maxValue: 45 },
            colorMode: colorMode.value,
            sampleMode: sampleMode.value,
            opacity: 0.82,
        }).addTo(map)

        map.fitBounds([
            [grid.minLat, grid.minLng],
            [grid.maxLat, grid.maxLng],
        ], { padding: [20, 20] })
        resizeObserver = new ResizeObserver(() => map?.invalidateSize())
        resizeObserver.observe(mapElement.value)
        status.value = `${grid.width} × ${grid.height} 个格点已上传 GPU`
    } catch (error) {
        status.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

const updateColorMode = () => rasterLayer?.setColorMode(colorMode.value)
const updateSampleMode = () => rasterLayer?.setSampleMode(sampleMode.value)

onMounted(() => void initialize())

onBeforeUnmount(() => {
    resizeObserver?.disconnect()
    map?.remove()
    rasterLayer = null
    map = null
})
</script>

<template>
    <section class="sampling-demo">
        <div class="controls">
            <label>
                颜色模式
                <select v-model="colorMode" @change="updateColorMode">
                    <option value="step">分段</option>
                    <option value="smooth">平滑</option>
                </select>
            </label>
            <label>
                采样模式
                <select v-model="sampleMode" @change="updateSampleMode">
                    <option value="cell">原始格点</option>
                    <option value="interpolate">双线性插值</option>
                </select>
            </label>
            <p>{{ status }}</p>
        </div>

        <div class="legend">
            <div class="legend-title">
                <strong>完整色标</strong>
                <span>{{ colorMode === 'step' ? '按区间取色' : '相邻颜色连续过渡' }}</span>
            </div>
            <div class="legend-colors">
                <span
                    v-for="(stop, index) in rasterDemoColorStops"
                    :key="`${stop.min}-${stop.max}-${index}`"
                    :style="{ backgroundColor: stop.color }"
                />
            </div>
            <div class="legend-ticks">
                <span>-72</span><span>-40</span><span>-20</span><span>0</span><span>20</span><span>45+</span>
            </div>
        </div>

        <div ref="mapElement" class="map" />
    </section>
</template>

色标格式 ​

每个 RasterColorStopInput 使用 min、max 和 color 描述一个数值区间。color 支持 CSS 颜色字符串；最后一个区间可以使用 Number.POSITIVE_INFINITY 覆盖更高数值。

ts
const colorStops = [
    { min: -4, max: 0, color: '#00ccff' },
    { min: 0, max: 4, color: '#00ffc6' },
    { min: 4, max: Number.POSITIVE_INFINITY, color: '#00ff60' },
]

API ​

API参数返回值说明
normalizeColorStops(colorStops)RasterColorStopInput[]RasterColorStop[]校验区间并把颜色归一化为 0 到 1 的 RGBA
parseRasterColor(color)string[number, number, number, number]解析单个 CSS 颜色
setColorStops(colorStops)RasterColorStopInput[]void动态替换完整色标
setColorRange(colorRange){ minValue, maxValue } | nullvoid过滤当前显示的数值范围，null 取消过滤
setColorMode(colorMode)'step' | 'smooth'void切换分段或平滑着色
setSampleMode(sampleMode)'cell' | 'interpolate'void切换格点或双线性插值采样

setColorMode 与 setSampleMode 只更新渲染状态；栅格数组与色标纹理无需重新加载。

栅格 ​

本节由codex施工

栅格模块负责把规则经纬度网格加载为统一的 RasterGrid，再交给 Leaflet、Mars3D 或通用 GPU 渲染器显示。数据加载、颜色映射、采样、查询和裁剪使用同一套数据约定，不需要为不同地图重复转换原始数组。

功能范围 ​

模块入口 ​

入口用途
m4-w-fast/raster-rendering与地图框架无关的数据、查询、WebGL2/WebGPU Renderer 和地理瓦片 Renderer
m4-w-fast/raster-leafletLeaflet 栅格图层及其完整控制、查询和裁剪能力
m4-w-fast/raster-mars3dMars3D/Cesium 贴地 ImageryProvider 和指定高度栅格平面
m4-w-fast/raster-overlay兼容聚合入口，包含 Leaflet 相关导出

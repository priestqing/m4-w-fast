Mars3D 贴地栅格 ​

本节由codex施工

createMars3dRasterImageryProvider 返回符合 Cesium ImageryProvider 协议的 WebGPU 栅格瓦片提供器。Mars3D/Cesium 负责瓦片缓存、球面贴图、相机和地形，包负责按 GeographicTilingScheme 生成透明栅格瓦片。

运行示例 ​

示例使用真实 2510270910.015、完整色标和 620000.json 边界。地图运行时按需加载，Provider 直接加入当前 Mars3D 地图的 Cesium imageryLayers。

关键代码 ​

vue
<!-- 使用公开 ImageryProvider 在 Mars3D 地球表面显示真实 WebGPU 栅格瓦片。 -->
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import {
    createMars3dRasterImageryProvider,
} from 'm4-w-fast/raster-mars3d'
import type {
    CesiumRuntime,
    Mars3dRasterImageryProvider,
    RasterClipOptions,
} from 'm4-w-fast/raster-mars3d'
import boundaryUrl from './data/620000.json?url'
import { loadMars3dDemoRuntime } from './mars3dDemoRuntime'
import { loadRasterDemoGrid, rasterDemoColorStops } from './rasterLeafletDemoData'

interface IImageryLayerCollection {
    addImageryProvider: (provider: unknown) => unknown
    remove: (layer: unknown, destroy?: boolean) => boolean
}

interface IMars3dMap {
    viewer: {
        imageryLayers: IImageryLayerCollection
    }
    destroy: () => void
}

interface IMars3dMapRuntime {
    Map: new (container: HTMLElement, options: unknown) => IMars3dMap
}

const mapElement = ref<HTMLDivElement | null>(null)
const status = ref('正在加载 Mars3D、真实栅格与边界')
const opacity = ref(0.82)

let map: IMars3dMap | null = null
let provider: Mars3dRasterImageryProvider | null = null
let imageryLayer: unknown = null

const initialize = async () => {
    if (!mapElement.value) return

    try {
        if (!navigator.gpu) throw new Error('当前浏览器不支持 WebGPU')
        const [{ Cesium, mars3d }, grid, boundaryResponse] = await Promise.all([
            loadMars3dDemoRuntime(),
            loadRasterDemoGrid(),
            fetch(boundaryUrl),
        ])
        if (!boundaryResponse.ok) throw new Error(`620000.json 加载失败：${boundaryResponse.status}`)
        const boundary = await boundaryResponse.json() as RasterClipOptions['data']

        const mars3dRuntime = mars3d as IMars3dMapRuntime
        map = new mars3dRuntime.Map(mapElement.value, {
            scene: {
                center: { lat: 37.65, lng: 100.55, alt: 1800000, heading: 0, pitch: -90 },
            },
            terrain: false,
            basemaps: [{
                name: 'OpenStreetMap',
                type: 'xyz',
                url: 'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
                show: true,
            }],
        })

        provider = createMars3dRasterImageryProvider(Cesium as CesiumRuntime, {
            grid,
            colorStops: rasterDemoColorStops,
            colorRange: { minValue: -72, maxValue: 45 },
            colorMode: 'step',
            sampleMode: 'interpolate',
            opacity: 1,
            clip: { data: boundary, mode: 'direct' },
            minimumLevel: 0,
            maximumLevel: 10,
        })
        imageryLayer = map.viewer.imageryLayers.addImageryProvider(provider)
        updateOpacity()
        status.value = `${grid.width} × ${grid.height} 个真实格点 · GeographicTilingScheme`
    } catch (error) {
        status.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

const updateOpacity = () => {
    const layer = imageryLayer as { alpha?: number } | null
    if (layer) layer.alpha = opacity.value
}

onMounted(() => void initialize())

onBeforeUnmount(() => {
    if (map && imageryLayer) map.viewer.imageryLayers.remove(imageryLayer, false)
    provider?.destroy()
    map?.destroy()
    provider = null
    imageryLayer = null
    map = null
})
</script>

<template>
    <section class="mars3d-demo">
        <div class="controls">
            <label>
                图层透明度 {{ opacity.toFixed(2) }}
                <input v-model.number="opacity" type="range" min="0" max="1" step="0.01" @input="updateOpacity">
            </label>
            <span>{{ status }}</span>
        </div>
        <div ref="mapElement" class="map" />
    </section>
</template>

// 按需加载 Mars3D/Cesium 运行时，供两个栅格文档示例复用。
const CESIUM_SCRIPT = 'https://registry.npmmirror.com/mars3d-cesium/1.143.0/files/Build/Cesium/Cesium.js'
const CESIUM_STYLE = 'https://registry.npmmirror.com/mars3d-cesium/1.143.0/files/Build/Cesium/Widgets/widgets.css'
const MARS3D_SCRIPT = 'https://registry.npmmirror.com/mars3d/3.11.5/files/mars3d.js'
const MARS3D_STYLE = 'https://registry.npmmirror.com/mars3d/3.11.5/files/mars3d.css'

interface IRuntimeWindow extends Window {
    Cesium?: unknown
    mars3d?: unknown
}

export interface IMars3dDemoRuntime {
    Cesium: unknown
    mars3d: unknown
}

let runtimePromise: Promise<IMars3dDemoRuntime> | null = null

const loadStyle = (id: string, href: string) => {
    if (document.getElementById(id)) return
    const link = document.createElement('link')
    link.id = id
    link.rel = 'stylesheet'
    link.href = href
    document.head.appendChild(link)
}

const loadScript = (id: string, source: string) => new Promise<void>((resolve, reject) => {
    const existing = document.getElementById(id) as HTMLScriptElement | null
    if (existing?.dataset.loaded === 'true') {
        resolve()
        return
    }

    const script = existing ?? document.createElement('script')
    script.id = id
    script.src = source
    script.addEventListener('load', () => {
        script.dataset.loaded = 'true'
        resolve()
    }, { once: true })
    script.addEventListener('error', () => reject(new Error(`${source} 加载失败`)), { once: true })
    if (!existing) document.head.appendChild(script)
})

export const loadMars3dDemoRuntime = (): Promise<IMars3dDemoRuntime> => {
    if (runtimePromise) return runtimePromise

    runtimePromise = (async () => {
        const runtimeWindow = window as IRuntimeWindow
        loadStyle('m4-demo-cesium-style', CESIUM_STYLE)
        loadStyle('m4-demo-mars3d-style', MARS3D_STYLE)
        if (!runtimeWindow.Cesium) await loadScript('m4-demo-cesium-script', CESIUM_SCRIPT)
        if (!runtimeWindow.mars3d) await loadScript('m4-demo-mars3d-script', MARS3D_SCRIPT)
        if (!runtimeWindow.Cesium || !runtimeWindow.mars3d) throw new Error('Mars3D 或 Cesium 运行时不可用')
        return {
            Cesium: runtimeWindow.Cesium,
            mars3d: runtimeWindow.mars3d,
        }
    })()

    return runtimePromise
}

创建参数 ​

调用 createMars3dRasterImageryProvider(Cesium, options)。

参数类型默认值必填说明
gridRasterGrid-是待绘制的规则栅格
colorStopsRasterColorStopInput[]-是数值区间与 CSS 颜色
colorRangeRasterColorRange色标范围否当前显示值范围
opacitynumber1否瓦片内容透明度
colorMode'step' | 'smooth''step'否分段或平滑着色
sampleMode'cell' | 'interpolate''interpolate'否格点或双线性插值
clipRasterClipOptions-否GeoJSON 裁剪数据与模式
tileWidth / tileHeightnumber256否瓦片尺寸，当前必须相同
minimumLevelnumber0否最小瓦片层级
maximumLevelnumber-否最大瓦片层级
rectangleCesiumRectangleLike栅格范围否Provider 可见矩形
ellipsoidunknownCesium 默认椭球否GeographicTilingScheme 使用的椭球
creditstring | unknown-否Cesium 版权信息

Provider API ​

成员返回值说明
requestImage(x, y, level, request?)Promise<HTMLCanvasElement> | undefined生成相互独立的透明瓦片 Canvas
getTileCredits()unknown[] | undefined返回当前版权信息
pickFeatures()undefined当前不提供瓦片要素拾取
rendererWebgpuRasterTileRenderer访问底层渲染器并动态更新数据或样式
destroy()void释放 WebGPU 资源；移除宿主图层时必须调用

WebgpuRasterTileRenderer ​

底层 renderer 提供 setGrid、setColorStops、setColorRange、setOpacity、setColorMode、setSampleMode、setClip 和 setClipMode。这些方法会影响之后生成的瓦片；已经进入 Cesium 缓存的旧瓦片，需要由宿主图层触发刷新。

当前只支持 Cesium GeographicTilingScheme，不接收 Web Mercator 瓦片编号。

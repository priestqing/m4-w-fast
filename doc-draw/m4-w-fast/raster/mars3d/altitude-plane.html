Mars3D 实高栅格平面 ​

本节由codex施工

createMars3dRasterPlaneLayer 返回完整的 Mars3D BaseLayer。图层在指定的椭球绝对高度生成栅格平面，并负责相机监听、可见瓦片计算、GPU 纹理、Cesium Primitive、缓存与资源释放。

运行示例 ​

示例加载真实 2510270910.015 和完整色标。拖动高度与透明度控制条，或切换颜色、采样模式时，直接调用 layer.update() 更新现有图层。

关键代码 ​

vue
<!-- 使用公开 PlaneLayer 在指定绝对高度显示并实时更新真实栅格。 -->
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import { createMars3dRasterPlaneLayer } from 'm4-w-fast/raster-mars3d'
import type {
    IMars3dRasterPlaneLayer,
    IMars3dRuntime,
    RasterColorMode,
    RasterSampleMode,
} from 'm4-w-fast/raster-mars3d'
import { loadMars3dDemoRuntime } from './mars3dDemoRuntime'
import { loadRasterDemoGrid, rasterDemoColorStops } from './rasterLeafletDemoData'

interface IMars3dMap {
    addLayer: (layer: unknown) => void
    removeLayer: (layer: unknown, destroy?: boolean) => void
    destroy: () => void
}

interface IMars3dMapRuntime {
    Map: new (container: HTMLElement, options: unknown) => IMars3dMap
}

const mapElement = ref<HTMLDivElement | null>(null)
const status = ref('正在加载 Mars3D 与真实栅格')
const height = ref(5000)
const opacity = ref(0.82)
const colorMode = ref<RasterColorMode>('step')
const sampleMode = ref<RasterSampleMode>('interpolate')

let map: IMars3dMap | null = null
let rasterLayer: IMars3dRasterPlaneLayer | null = null

const initialize = async () => {
    if (!mapElement.value) return

    try {
        if (!navigator.gpu) throw new Error('当前浏览器不支持 WebGPU')
        const [{ mars3d }, grid] = await Promise.all([
            loadMars3dDemoRuntime(),
            loadRasterDemoGrid(),
        ])
        const mapRuntime = mars3d as IMars3dMapRuntime
        map = new mapRuntime.Map(mapElement.value, {
            scene: {
                center: { lat: 37.65, lng: 100.55, alt: 650000, heading: 0, pitch: -55 },
            },
            terrain: false,
            basemaps: [{
                name: 'OpenStreetMap',
                type: 'xyz',
                url: 'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
                show: true,
            }],
        })

        rasterLayer = createMars3dRasterPlaneLayer(mars3d as IMars3dRuntime, {
            name: '指定高度栅格平面',
            grid,
            height: height.value,
            colorStops: rasterDemoColorStops,
            colorRange: { minValue: -72, maxValue: 45 },
            colorMode: colorMode.value,
            sampleMode: sampleMode.value,
            opacity: opacity.value,
        })
        map.addLayer(rasterLayer)
        status.value = `${grid.width} × ${grid.height} 个真实格点 · 椭球绝对高度 ${height.value} 米`
    } catch (error) {
        status.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

const updateLayer = () => {
    rasterLayer?.update({
        height: height.value,
        opacity: opacity.value,
        colorMode: colorMode.value,
        sampleMode: sampleMode.value,
    })
    status.value = `图层已更新 · 椭球绝对高度 ${height.value} 米`
}

onMounted(() => void initialize())

onBeforeUnmount(() => {
    if (map && rasterLayer) map.removeLayer(rasterLayer, false)
    rasterLayer?.destroy()
    map?.destroy()
    rasterLayer = null
    map = null
})
</script>

<template>
    <section class="mars3d-demo">
        <div class="controls">
            <label>
                绝对高度 {{ height }} 米
                <input v-model.number="height" type="range" min="0" max="20000" step="500" @input="updateLayer">
            </label>
            <label>
                透明度 {{ opacity.toFixed(2) }}
                <input v-model.number="opacity" type="range" min="0" max="1" step="0.01" @input="updateLayer">
            </label>
            <label>
                颜色模式
                <select v-model="colorMode" @change="updateLayer">
                    <option value="step">分段</option>
                    <option value="smooth">平滑</option>
                </select>
            </label>
            <label>
                采样模式
                <select v-model="sampleMode" @change="updateLayer">
                    <option value="cell">原始格点</option>
                    <option value="interpolate">双线性插值</option>
                </select>
            </label>
        </div>
        <p class="status">{{ status }}</p>
        <div ref="mapElement" class="map" />
    </section>
</template>

// 按需加载 Mars3D/Cesium 运行时，供两个栅格文档示例复用。
const CESIUM_SCRIPT = 'https://registry.npmmirror.com/mars3d-cesium/1.143.0/files/Build/Cesium/Cesium.js'
const CESIUM_STYLE = 'https://registry.npmmirror.com/mars3d-cesium/1.143.0/files/Build/Cesium/Widgets/widgets.css'
const MARS3D_SCRIPT = 'https://registry.npmmirror.com/mars3d/3.11.5/files/mars3d.js'
const MARS3D_STYLE = 'https://registry.npmmirror.com/mars3d/3.11.5/files/mars3d.css'

interface IRuntimeWindow extends Window {
    Cesium?: unknown
    mars3d?: unknown
}

export interface IMars3dDemoRuntime {
    Cesium: unknown
    mars3d: unknown
}

let runtimePromise: Promise<IMars3dDemoRuntime> | null = null

const loadStyle = (id: string, href: string) => {
    if (document.getElementById(id)) return
    const link = document.createElement('link')
    link.id = id
    link.rel = 'stylesheet'
    link.href = href
    document.head.appendChild(link)
}

const loadScript = (id: string, source: string) => new Promise<void>((resolve, reject) => {
    const existing = document.getElementById(id) as HTMLScriptElement | null
    if (existing?.dataset.loaded === 'true') {
        resolve()
        return
    }

    const script = existing ?? document.createElement('script')
    script.id = id
    script.src = source
    script.addEventListener('load', () => {
        script.dataset.loaded = 'true'
        resolve()
    }, { once: true })
    script.addEventListener('error', () => reject(new Error(`${source} 加载失败`)), { once: true })
    if (!existing) document.head.appendChild(script)
})

export const loadMars3dDemoRuntime = (): Promise<IMars3dDemoRuntime> => {
    if (runtimePromise) return runtimePromise

    runtimePromise = (async () => {
        const runtimeWindow = window as IRuntimeWindow
        loadStyle('m4-demo-cesium-style', CESIUM_STYLE)
        loadStyle('m4-demo-mars3d-style', MARS3D_STYLE)
        if (!runtimeWindow.Cesium) await loadScript('m4-demo-cesium-script', CESIUM_SCRIPT)
        if (!runtimeWindow.mars3d) await loadScript('m4-demo-mars3d-script', MARS3D_SCRIPT)
        if (!runtimeWindow.Cesium || !runtimeWindow.mars3d) throw new Error('Mars3D 或 Cesium 运行时不可用')
        return {
            Cesium: runtimeWindow.Cesium,
            mars3d: runtimeWindow.mars3d,
        }
    })()

    return runtimePromise
}

创建参数 ​

调用 createMars3dRasterPlaneLayer(mars3d, options)。

参数类型默认值必填说明
gridRasterGrid-是待绘制的规则栅格
heightnumber-是WGS84 椭球绝对高度，单位米
colorStopsRasterColorStopInput[]-是数值区间与 CSS 颜色
colorRangeRasterColorRange色标范围否当前显示值范围
colorMode'step' | 'smooth''step'否分段或平滑着色
sampleMode'cell' | 'interpolate''interpolate'否格点或双线性插值
opacitynumber1否图层透明度
namestring-否Mars3D 图层名称
showbooleantrue否初始显隐状态

图层 API ​

成员参数返回值说明
height-number当前椭球绝对高度
update(options)IMars3dRasterPlaneLayerUpdatevoid局部更新数据、高度、色标或显示配置
destroy(noDel?)boolean?void销毁图层及其 Cesium/WebGPU 资源

update 支持 grid、height、colorStops、colorRange、colorMode、sampleMode 和 opacity，没有传入的字段保持不变。

高度说明 ​

  • height 是相对 WGS84 椭球面的绝对高度，不采样地形。
  • 所有瓦片使用同一个高度，并由 Cesium RectangleGeometry 沿椭球曲面生成。
  • 图层不会主动应用业务侧的垂直夸张。
  • 数据或样式更新时会取消旧请求，并在新瓦片完成后替换当前内容。

查询与交互 ​

本节由codex施工

Leaflet 栅格图层提供悬停回调、点击回调、Leaflet 自定义事件和主动坐标查询。查询直接读取原始 RasterGrid，返回数据值、格点索引、可见状态和失败原因。

运行示例 ​

示例使用真实 MICAPS4 文件 2510270910.015。在地图上移动鼠标可触发 onHover，点击地图可接收 raster:click。主动查询支持输入经纬度调用 queryValueAt()，也可以使用 queryValueAtLatLng() 查询地图中心。

关键代码 ​

vue
<!-- 展示 Leaflet 栅格的悬停、点击事件和主动坐标查询。 -->
<script setup lang="ts">
import { computed, onBeforeUnmount, onMounted, ref } from 'vue'
import * as L from 'leaflet'
import 'leaflet/dist/leaflet.css'
import { createRasterLeafletLayer } from 'm4-w-fast/raster-overlay'
import type {
    RasterLeafletLayer,
    RasterQueryEvent,
    RasterQueryResult,
} from 'm4-w-fast/raster-overlay'
import { loadRasterDemoGrid, rasterDemoColorStops } from './rasterLeafletDemoData'

interface IQueryCard {
    title: string
    coordinate: string
    value: string
    rawValue: string
    gridIndex: string
    state: string
}

const mapElement = ref<HTMLDivElement | null>(null)
const status = ref('等待初始化')
const ready = ref(false)
const hoverCount = ref(0)
const clickCount = ref(0)
const hoverResult = ref<IQueryCard>(createEmptyCard('悬停回调'))
const clickResult = ref<IQueryCard>(createEmptyCard('点击事件'))
const manualResult = ref<IQueryCard>(createEmptyCard('主动查询'))
const queryLongitude = ref(103.82)
const queryLatitude = ref(36.05)
const queryError = ref('')
const queryCards = computed(() => [hoverResult.value, clickResult.value, manualResult.value])

let map: L.Map | null = null
let rasterLayer: RasterLeafletLayer | null = null
let resizeObserver: ResizeObserver | null = null

function createEmptyCard(title: string): IQueryCard {
    return {
        title,
        coordinate: '等待操作',
        value: '--',
        rawValue: '--',
        gridIndex: '--',
        state: '未查询',
    }
}

const createQueryCard = (title: string, result: RasterQueryResult): IQueryCard => {
    return {
        title,
        coordinate: `${result.x.toFixed(3)}, ${result.y.toFixed(3)}`,
        value: result.valid ? result.value.toFixed(2) : '--',
        rawValue: result.valid ? result.rawValue.toFixed(2) : '--',
        gridIndex: result.valid ? `${result.gridX}, ${result.gridY}` : '--',
        state: `${result.reason} · ${result.visible ? '可见' : '不可见'}`,
    }
}

const handleRasterClick: L.LeafletEventHandlerFn = (event) => {
    const rasterEvent = event as RasterQueryEvent
    clickCount.value += 1
    clickResult.value = createQueryCard('点击事件', rasterEvent.result)
}

const queryMapCenter = () => {
    if (!map || !rasterLayer) return
    queryError.value = ''
    manualResult.value = createQueryCard('主动查询', rasterLayer.queryValueAtLatLng(map.getCenter()))
}

const queryCoordinate = () => {
    if (!rasterLayer) return

    const longitude = Number(queryLongitude.value)
    const latitude = Number(queryLatitude.value)
    if (!Number.isFinite(longitude) || !Number.isFinite(latitude)) {
        queryError.value = '请输入有效的经纬度'
        return
    }
    if (longitude < -180 || longitude > 180 || latitude < -90 || latitude > 90) {
        queryError.value = '经度范围为 -180～180，纬度范围为 -90～90'
        return
    }

    queryError.value = ''
    manualResult.value = createQueryCard('主动查询', rasterLayer.queryValueAt({
        x: longitude,
        y: latitude,
    }))
}

const initializeMap = async () => {
    if (!mapElement.value) return
    status.value = '正在加载真实栅格数据'

    try {
        const grid = await loadRasterDemoGrid()
        map = L.map(mapElement.value, {
            center: [36.05, 103.82],
            zoom: 5,
        })

        L.tileLayer('https://webrd0{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}', {
            subdomains: ['1', '2', '3', '4'],
            maxZoom: 18,
        }).addTo(map)

        map.createPane('raster-interaction-pane')
        const pane = map.getPane('raster-interaction-pane')
        if (pane) pane.style.zIndex = '420'

        rasterLayer = createRasterLeafletLayer({
            rendererType: 'webgl2',
            grid,
            colorStops: rasterDemoColorStops,
            colorRange: {
                minValue: -72,
                maxValue: 45,
            },
            opacity: 0.82,
            colorMode: 'step',
            sampleMode: 'interpolate',
            pane: 'raster-interaction-pane',
            tooltip: {
                enabled: true,
                position: 'follow',
                formatter: result => result.valid ? `当前值：${result.value.toFixed(2)}` : `状态：${result.reason}`,
            },
            onHover: result => {
                hoverCount.value += 1
                hoverResult.value = createQueryCard('悬停回调', result)
            },
        })

        rasterLayer.on('raster:click', handleRasterClick)
        rasterLayer.addTo(map)
        map.fitBounds([
            [grid.minLat, grid.minLng],
            [grid.maxLat, grid.maxLng],
        ], { padding: [24, 24] })

        resizeObserver = new ResizeObserver(() => map?.invalidateSize())
        resizeObserver.observe(mapElement.value)
        ready.value = true
        status.value = `${grid.width} × ${grid.height} 个真实格点已就绪`
    } catch (error) {
        status.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

onMounted(() => {
    void initializeMap()
})

onBeforeUnmount(() => {
    if (rasterLayer) rasterLayer.off('raster:click', handleRasterClick)
    resizeObserver?.disconnect()
    resizeObserver = null
    map?.remove()
    rasterLayer = null
    map = null
})
</script>

<template>
    <section class="interaction-demo">
        <header class="demo-header">
            <div>
                <h3>栅格查询与交互</h3>
                <p>移动鼠标、点击地图，或输入经纬度主动查询。</p>
            </div>
        </header>

        <div class="query-controls">
            <label>
                经度
                <input v-model.number="queryLongitude" type="number" min="-180" max="180" step="0.01">
            </label>
            <label>
                纬度
                <input v-model.number="queryLatitude" type="number" min="-90" max="90" step="0.01">
            </label>
            <button type="button" :disabled="!ready" @click="queryCoordinate">查询指定坐标</button>
            <button type="button" :disabled="!ready" @click="queryMapCenter">查询地图中心</button>
            <span v-if="queryError">{{ queryError }}</span>
        </div>

        <div class="event-summary">
            <span>悬停回调 {{ hoverCount }} 次</span>
            <span>点击事件 {{ clickCount }} 次</span>
            <span>{{ status }}</span>
        </div>

        <div class="query-cards">
            <article v-for="card in queryCards" :key="card.title">
                <strong>{{ card.title }}</strong>
                <dl>
                    <div><dt>坐标</dt><dd>{{ card.coordinate }}</dd></div>
                    <div><dt>缩放值</dt><dd>{{ card.value }}</dd></div>
                    <div><dt>原始值</dt><dd>{{ card.rawValue }}</dd></div>
                    <div><dt>格点索引</dt><dd>{{ card.gridIndex }}</dd></div>
                    <div><dt>状态</dt><dd>{{ card.state }}</dd></div>
                </dl>
            </article>
        </div>

        <div ref="mapElement" class="map" />
    </section>
</template>

创建参数 ​

这些参数属于 RasterLeafletLayerCreateOptions。

参数类型默认值说明
onHover(result: RasterQueryResult) => void-鼠标在地图内移动时执行
onClick(result: RasterQueryResult) => void-点击地图时执行
tooltip.enabledbooleanfalse是否启用内置提示框
tooltip.position'follow' | 'fixed''follow'跟随鼠标或固定显示
tooltip.formatter(result) => string内置文本自定义提示内容
queryOutsideClipbooleanfalse是否允许查询裁剪区域外的数据

主动查询方法 ​

方法参数返回值说明
queryValueAt{ x: number, y: number }RasterQueryResult按经纬度数值查询，x 为经度、y 为纬度
queryValueAtLatLngL.LatLngExpressionRasterQueryResult接收 Leaflet 坐标表达式
setQueryOutsideClipbooleanvoid动态控制裁剪区域外查询

主动查询是同步操作，适合在业务点击、定位或表单输入后立即读取结果。

Leaflet 事件 ​

事件事件对象说明
raster:hoverRasterQueryEvent地图内鼠标移动时触发
raster:clickRasterQueryEvent地图点击时触发

RasterQueryEvent 除了 result，还包含 Leaflet 的 latlng 和原始鼠标事件 originalEvent。

RasterQueryResult ​

字段类型说明
x、ynumber查询经纬度
rawValuenumber栅格中的原始值
valuenumber应用 valueScale 后的值
valueScalenumber当前数据缩放系数
gridX、gridYnumber命中的格点索引
validboolean是否取得有效数据
visibleboolean是否处于当前显示范围内
reasonRasterQueryReason查询结果状态

reason 可能为 ok、no-data、out-of-bounds、out-of-range 或 outside-clip。业务逻辑应先判断 valid，再使用 value。

使用建议 ​

  • onHover 会随鼠标移动高频触发，回调内应避免网络请求和复杂同步计算。
  • 回调与 raster:hover 事件会在同一次鼠标移动中触发，通常选择一种方式即可。
  • visible: false 不一定代表没有数值，也可能是被显示范围或裁剪边界过滤。
  • 图层移除前如注册了自定义事件处理函数，应使用 off() 解除绑定。

On this page

GeoJSON 数据（ReadFile） ​

本节由codex施工

ReadFileM4Fast 用于解析 MICAPS4 规则格点，并生成等值带 GeoJSON、Canvas 或逐格点数据。它适合需要矢量编辑、要素级样式、GeoJSON 导出和空间相交的场景。

如果最终目标只是把规则栅格持续显示在地图上，并频繁修改色标、范围或透明度，应优先使用 m4-w-fast/raster-overlay；ReadFile 的 GeoJSON 方案会把格点转换为大量多边形，生成和浏览器矢量绘制成本更高。

推荐流程 ​

text
MICAPS4 文件 → start() → getIsoBandsFastByMask() → clipDataByJson() → L.geoJSON()
  • 不透明填色且不要求分级互斥时，可以使用 getIsoBandsFast()。
  • 半透明填色建议使用 getIsoBandsFastByMask()，每个分级独立提取，避免依赖多层面覆盖形成最终颜色。
  • 需要行政区裁剪时，将生成结果和 Polygon/MultiPolygon 边界交给 clipDataByJson()。

运行示例 ​

示例解析真实 MICAPS4 文件 2510270910.015，使用完整分段色标生成等值带，再通过 Worker 与真实行政区边界相交。可以切换“挖孔等值带”和“普通等值带”，并实际调整透明度、过滤色标范围、叠加真实格点网格，观察 Feature 数量与每次矢量重绘耗时。

交互与性能观察 ​

控件当前方案执行的工作重点观察
透明度调用 L.GeoJSON.setStyle()，重新设置全部 Feature 的 SVG 样式连续拖动会反复遍历矢量要素
色标最小值、最大值根据 properties.z 过滤分级，再对全部 Feature 调用 setStyle()色标会同步变暗，被过滤的分级不再填色
真实格点网格调用 buildGridLineCanvas() 生成 nx × ny 网格，再通过 L.imageOverlay() 对齐数据范围首次开启需要额外生成大尺寸 Canvas
生成方式重新生成等值带并执行 Worker 边界裁剪普通模式 Feature 较少；挖孔模式更适合透明填色但计算量更高

性能面板记录 setStyle() 耗时、下一帧响应时间、遍历次数和网格 Canvas 首次生成耗时。GeoJSON/SVG 每次更新都要遍历现有 Feature；GPU 栅格图层只更新渲染参数。

示例没有提供鼠标取值提示。当前 ReadFileM4Fast 只负责数据转换和图形生成，没有实现栅格原值查询接口；需要查询能力时应使用具备 queryValueAt()、queryValueAtLatLng() 的栅格图层方案。

关键代码 ​

vue
<!-- 展示 ReadFile 使用真实 MICAPS4 数据生成并裁剪 GeoJSON 等值带。 -->
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import * as L from 'leaflet'
import 'leaflet/dist/leaflet.css'
import ReadFileM4Fast from 'm4-w-fast'
import intersectWorkerUrl from 'm4-w-fast/intersect.worker.js?url'
import type { FeatureCollection, MultiPolygon, Polygon } from 'geojson'
import micaps4Url from './data/2510270910.015?url'
import boundaryUrl from './data/620000.json?url'
import { rasterDemoColorStops } from './rasterLeafletDemoData'

interface IBoundaryProperties {
    name?: string
    adcode?: number
}

type BoundaryCollection = FeatureCollection<Polygon | MultiPolygon, IBoundaryProperties>
type GenerationMode = 'mask' | 'fast'

const mapElement = ref<HTMLDivElement | null>(null)
const generationMode = ref<GenerationMode>('mask')
const errorMessage = ref('')
const gridSummary = ref('--')
const dataRange = ref('--')
const parseTime = ref<number | null>(null)
const generationTime = ref<number | null>(null)
const featureCount = ref(0)
const computing = ref(false)
const opacity = ref(0.55)
const minVisibleValue = ref(-72)
const maxVisibleValue = ref(45)
const gridVisible = ref(false)
const gridBuildTime = ref<number | null>(null)
const styleUpdateTime = ref<number | null>(null)
const frameResponseTime = ref<number | null>(null)
const styleUpdateCount = ref(0)

const breaks = rasterDemoColorStops.map(stop => stop.min)
const colors = rasterDemoColorStops.map(stop => stop.color)

let map: L.Map | null = null
let reader: ReadFileM4Fast | null = null
let boundaryData: BoundaryCollection | null = null
let boundaryLayer: L.GeoJSON | null = null
let resultLayer: L.GeoJSON | null = null
let gridLayer: L.ImageOverlay | null = null
let resizeObserver: ResizeObserver | null = null
let operationId = 0
let styleFrame = 0

const getResultStyle: L.StyleFunction = feature => {
    const level = Number(feature?.properties?.z)
    const visible = level >= minVisibleValue.value && level <= maxVisibleValue.value

    return {
        fillColor: reader?.getColorFast(level, breaks, colors) ?? 'transparent',
        fillOpacity: visible ? opacity.value : 0,
        stroke: false,
        smoothFactor: 0,
    }
}

const applyVectorStyle = () => {
    if (!resultLayer || computing.value) return

    const startedAt = performance.now()
    resultLayer.setStyle(getResultStyle)
    styleUpdateTime.value = performance.now() - startedAt
    styleUpdateCount.value += 1
    if (styleFrame) window.cancelAnimationFrame(styleFrame)
    styleFrame = window.requestAnimationFrame(() => {
        frameResponseTime.value = performance.now() - startedAt
        styleFrame = 0
    })
}

const updateOpacity = () => {
    applyVectorStyle()
}

const updateColorRange = (source: 'min' | 'max') => {
    if (minVisibleValue.value > maxVisibleValue.value) {
        if (source === 'min') maxVisibleValue.value = minVisibleValue.value
        else minVisibleValue.value = maxVisibleValue.value
    }
    applyVectorStyle()
}

const toggleGridLines = () => {
    if (!map || !reader) return

    if (!gridVisible.value) {
        if (gridLayer) map.removeLayer(gridLayer)
        return
    }

    if (!gridLayer) {
        const startedAt = performance.now()
        const canvas = reader.buildGridLineCanvas({
            width: reader.nx,
            pixelRatio: 1,
            strokeStyle: 'rgba(15, 23, 42, 0.5)',
            lineWidth: 0.45,
        })
        if (!canvas) {
            gridVisible.value = false
            errorMessage.value = '网格线 Canvas 生成失败'
            return
        }

        const endLng = reader.minLng + reader.nx * reader.gjLng
        const endLat = reader.minLat + reader.ny * reader.gjLat
        gridLayer = L.imageOverlay(canvas.toDataURL('image/png'), [
            [Math.min(reader.minLat, endLat), Math.min(reader.minLng, endLng)],
            [Math.max(reader.minLat, endLat), Math.max(reader.minLng, endLng)],
        ], {
            pane: 'geojson-grid-pane',
            opacity: 0.55,
            interactive: false,
        })
        gridBuildTime.value = performance.now() - startedAt
    }

    gridLayer.addTo(map)
}

const loadBoundary = async (): Promise<BoundaryCollection> => {
    const response = await fetch(boundaryUrl)
    if (!response.ok) throw new Error(`GeoJSON 边界加载失败：${response.status}`)
    return await response.json() as BoundaryCollection
}

const buildGeoJson = async () => {
    if (!reader || !map || !boundaryData || computing.value) return

    const currentOperation = ++operationId
    const startedAt = performance.now()
    computing.value = true
    errorMessage.value = ''

    try {
        const isoBands = generationMode.value === 'mask'
            ? reader.getIsoBandsFastByMask(breaks)
            : reader.getIsoBandsFast(breaks)
        const clipped = await reader.clipDataByJson(
            isoBands,
            boundaryData,
            intersectWorkerUrl,
        )
        if (currentOperation !== operationId || !map) return

        if (resultLayer) map.removeLayer(resultLayer)
        resultLayer = L.geoJSON(clipped, {
            pane: 'geojson-result-pane',
            style: getResultStyle,
        }).addTo(map)

        featureCount.value = clipped.features.length
        generationTime.value = performance.now() - startedAt
        styleUpdateTime.value = null
        frameResponseTime.value = null
        styleUpdateCount.value = 0
    } catch (error) {
        errorMessage.value = error instanceof Error ? error.message : 'GeoJSON 生成失败'
    } finally {
        if (currentOperation === operationId) computing.value = false
    }
}

const initialize = async () => {
    if (!mapElement.value) return
    errorMessage.value = ''

    try {
        map = L.map(mapElement.value, {
            center: [36.05, 103.82],
            zoom: 5,
        })
        L.tileLayer('https://webrd0{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}', {
            subdomains: ['1', '2', '3', '4'],
            maxZoom: 18,
        }).addTo(map)

        map.createPane('geojson-result-pane')
        map.createPane('geojson-grid-pane')
        map.createPane('geojson-boundary-pane')
        const resultPane = map.getPane('geojson-result-pane')
        const gridPane = map.getPane('geojson-grid-pane')
        const outlinePane = map.getPane('geojson-boundary-pane')
        if (resultPane) resultPane.style.zIndex = '420'
        if (gridPane) gridPane.style.zIndex = '425'
        if (outlinePane) outlinePane.style.zIndex = '430'

        const parseStartedAt = performance.now()
        reader = new ReadFileM4Fast(micaps4Url)
        const [, boundary] = await Promise.all([
            reader.start(),
            loadBoundary(),
        ])
        parseTime.value = performance.now() - parseStartedAt
        boundaryData = boundary
        gridSummary.value = `${reader.nx} × ${reader.ny}`
        dataRange.value = `${reader.minVal.toFixed(2)} ～ ${reader.maxVal.toFixed(2)}`

        boundaryLayer = L.geoJSON(boundary, {
            pane: 'geojson-boundary-pane',
            style: {
                color: '#ff2d55',
                fill: false,
                weight: 2,
            },
        }).addTo(map)
        map.fitBounds(boundaryLayer.getBounds(), { padding: [24, 24] })

        resizeObserver = new ResizeObserver(() => map?.invalidateSize())
        resizeObserver.observe(mapElement.value)
        await buildGeoJson()
    } catch (error) {
        errorMessage.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

onMounted(() => {
    void initialize()
})

onBeforeUnmount(() => {
    operationId += 1
    if (styleFrame) window.cancelAnimationFrame(styleFrame)
    styleFrame = 0
    resizeObserver?.disconnect()
    resizeObserver = null
    map?.remove()
    resultLayer = null
    gridLayer = null
    boundaryLayer = null
    boundaryData = null
    reader = null
    map = null
})
</script>

<template>
    <section class="geojson-demo">
        <header class="demo-header">
            <div>
                <h3>ReadFile GeoJSON 等值带</h3>
                <p>真实文件解析、分级面生成、Worker 边界裁剪和 Leaflet 矢量显示。</p>
            </div>
            <div class="actions">
                <label>
                    {{ computing ? '正在生成' : '生成方式' }}
                    <select v-model="generationMode" :disabled="computing" @change="buildGeoJson">
                        <option value="mask">挖孔等值带</option>
                        <option value="fast">普通等值带</option>
                    </select>
                </label>
            </div>
        </header>

        <div class="controls">
            <label>
                透明度 {{ opacity.toFixed(2) }}
                <input
                    v-model.number="opacity"
                    type="range"
                    min="0"
                    max="1"
                    step="0.01"
                    :disabled="computing || !resultLayer"
                    @input="updateOpacity"
                >
            </label>
            <label>
                色标最小值 {{ minVisibleValue }}
                <input
                    v-model.number="minVisibleValue"
                    type="range"
                    min="-72"
                    max="45"
                    step="1"
                    :disabled="computing || !resultLayer"
                    @input="updateColorRange('min')"
                >
            </label>
            <label>
                色标最大值 {{ maxVisibleValue }}
                <input
                    v-model.number="maxVisibleValue"
                    type="range"
                    min="-72"
                    max="45"
                    step="1"
                    :disabled="computing || !resultLayer"
                    @input="updateColorRange('max')"
                >
            </label>
            <label class="grid-toggle">
                <input
                    v-model="gridVisible"
                    type="checkbox"
                    :disabled="computing || !reader"
                    @change="toggleGridLines"
                >
                显示真实格点网格
            </label>
        </div>

        <div class="legend" aria-label="分段色标">
            <div class="legend-bar">
                <span
                    v-for="stop in rasterDemoColorStops"
                    :key="stop.min"
                    :style="{ backgroundColor: stop.color }"
                    :class="{ 'is-filtered': stop.min < minVisibleValue || stop.min > maxVisibleValue }"
                />
            </div>
            <div class="legend-labels">
                <span>{{ rasterDemoColorStops[0].min }}</span>
                <span>{{ rasterDemoColorStops[Math.floor(rasterDemoColorStops.length / 2)].min }}</span>
                <span>{{ rasterDemoColorStops[rasterDemoColorStops.length - 1].min }}+</span>
            </div>
        </div>

        <div class="metrics">
            <div><strong>{{ gridSummary }}</strong><span>真实格点</span></div>
            <div><strong>{{ dataRange }}</strong><span>数据范围</span></div>
            <div><strong>{{ parseTime === null ? '--' : `${parseTime.toFixed(0)} ms` }}</strong><span>文件解析</span></div>
            <div><strong>{{ generationTime === null ? '--' : `${generationTime.toFixed(0)} ms` }}</strong><span>生成与裁剪</span></div>
            <div><strong>{{ featureCount }}</strong><span>GeoJSON Feature</span></div>
        </div>

        <div class="performance-panel">
            <div><strong>{{ styleUpdateCount }} 次</strong><span>矢量样式遍历</span></div>
            <div><strong>{{ styleUpdateTime === null ? '--' : `${styleUpdateTime.toFixed(1)} ms` }}</strong><span>同步 setStyle</span></div>
            <div><strong>{{ frameResponseTime === null ? '--' : `${frameResponseTime.toFixed(1)} ms` }}</strong><span>下一帧响应</span></div>
            <div><strong>{{ gridBuildTime === null ? '--' : `${gridBuildTime.toFixed(1)} ms` }}</strong><span>网格 Canvas 生成</span></div>
        </div>

        <p v-if="errorMessage" class="error-message">{{ errorMessage }}</p>

        <div class="map-shell">
            <div ref="mapElement" class="map" />
            <span class="boundary-caption">红线为真实行政区边界</span>
        </div>
    </section>
</template>

导入 ​

ts
import ReadFileM4Fast from 'm4-w-fast'
import intersectWorkerUrl from 'm4-w-fast/intersect.worker.js?url'
import type {
    CanvasOptions,
    JSONData,
    ParamsConfig,
    Point,
    ReadConfig,
} from 'm4-w-fast'

UMD 文件暴露的全局构造函数为 M4WFast。使用构建工具时推荐使用默认 ESM 导入。

文件与参数数据 ​

MICAPS4 文件 ​

ts
const reader = new ReadFileM4Fast(fileUrl)
await reader.start()

start() 完成后可以读取 nx、ny、minLng、minLat、gjLng、gjLat、values、minVal 和 maxVal。

参数数据 ​

不传文件地址时，通过 setParams() 直接设置规则格点；这种方式不需要再调用 start()。

ts
const reader = new ReadFileM4Fast()

reader.setParams({
    values,
    nx,
    ny,
    minLng,
    minLat,
    gjLng,
    gjLat,
})

文件方式和参数方式选择一种即可。不要在同一个实例上把两种初始化流程混合使用。

GeoJSON 方法 ​

方法返回值状态说明
getIsoBandsFast(breaks)FeatureCollection当前可用生成普通等值带，每个 Feature 的 properties.z 为分级下限
getIsoBandsFastByMask(breaks)FeatureCollection新增并推荐用于透明填色按分级生成互斥面，并保留多边形内环
clipDataByJson(isoBands, boundary, workerUrl, useCpuCount?)Promise<FeatureCollection>当前可用使用 Worker 将等值带与边界相交
getColorFast(z, breaks, colors)string当前可用根据 properties.z 取得对应 CSS 颜色
getJsonData()JSONData[]当前可用展开为 { lng, lat, val } 格点数组
updateGridCanvas(points, updateVal)Point[]当前可用修改多边形范围内的内部格点值，并返回命中的坐标

分级规则 ​

breaks 是每个分级的下限数组，colors 应与其一一对应。最后一级的上限按正无穷处理。

ts
const breaks = [-20, -16, -12, -8, -4, 0, 4, 8]
const colors = ['#fff', '#0030ff', '#0079ff', '#00a8ff', '#00ccff', '#00eaff', '#00ffc6', '#00ff60']

Worker 裁剪 ​

ts
const isoBands = reader.getIsoBandsFastByMask(breaks)
const clipped = await reader.clipDataByJson(
    isoBands,
    boundaryGeoJson,
    intersectWorkerUrl,
)

boundaryGeoJson 必须是包含 Polygon 或 MultiPolygon 的 FeatureCollection。useCpuCount 可以限制 Worker 数量；省略时当前实现根据 navigator.hardwareConcurrency 计算。

Canvas 方法 ​

方法输出用途
getIsoBandsCanvas(breaks, colors, options?)HTMLCanvasElement | null将等值带直接绘制到普通 Canvas
getIsoBandsCanvasByMap(breaks, colors, map, options?)HTMLCanvasElement | null按 Leaflet 投影后的像素范围创建 Canvas
buildGridLineCanvas(options?)HTMLCanvasElement | null只绘制规则格网线
buildGridCanvas(breaks, colors, options?)HTMLCanvasElement | null逐格点绘制色块，可叠加格网线
buildGridCanvasClipByJson(breaks, colors, boundary, options?)HTMLCanvasElement | null逐格点填色后使用 GeoJSON 边界裁剪

Canvas 结果不会自动成为地图图层。需要显示在 Leaflet 时，可以转换为 Data URL 或 Blob URL，再使用 L.imageOverlay() 与数据经纬度范围对齐。

API 版本状态 ​

当前安装的 m4-w-fast@1.0.12 没有正式标记 @deprecated 的公开方法。

状态：✅ 保留　🆕 新增　❌ 已移除

API状态替代方式或说明
getIsoBandsFast()✅ 保留不透明填色或不需要互斥分级时继续使用
getIsoBandsFastByMask()🆕 新增半透明、内环和分级互斥场景优先使用
getIsoBandsFastByWorker()❌ 已移除当前版本没有实现和类型声明；使用同步生成方法，裁剪阶段使用 clipDataByJson() Worker
getIsoBandsByLayerBreak()❌ 已移除当前版本没有实现和类型声明；传入只包含目标阈值的 breaks，或从完整结果中过滤 properties.z
buildGridCanvas(options)❌ 旧签名已移除使用 buildGridCanvas(breaks, colors, options)
clipDataByJson()✅ 保留没有弃用，但必须显式传入 Worker URL
useCpuCount✅ 保留仍是 clipDataByJson() 的可选第四个参数

不要继续从旧代码复制已经移除的方法名；TypeScript 声明和运行时都不会提供这些成员。

类型说明 ​

ReadConfig ​

参数类型默认值说明
convertTemKtoCbooleanfalse按当前实现对每个值减去 272.15
plusOffsetnumber-为每个值增加偏移量

当前实现使用 if / else if 处理这两个选项；同时传入时只有 convertTemKtoC 生效。参数数据需要转换时，更稳妥的做法是先处理 values，再调用不带 ReadConfig 的 setParams()。

ParamsConfig ​

参数类型说明

nx、nynumber栅格列数和行数
minLng、minLatnumber起始经纬度
gjLng、gjLatnumber经度和纬度方向格距，纬度格距允许为负数

参数类型说明

类型声明注意事项 ​

默认导入得到的 ReadFileM4Fast 类声明包含 getIsoBandsFastByMask()、getIsoBandsCanvasByMap() 和 updateGridCanvas()。当前导出的 IReadFileM4 interface 没有同步列出这三个成员，因此不要把实例主动收窄为 IReadFileM4，否则 TypeScript 无法访问这些方法。

ts
// 推荐：保留具体类类型
const reader = new ReadFileM4Fast(fileUrl)

// 不建议：会丢失部分当前类方法的类型
// const reader: IReadFileM4 = new ReadFileM4Fast(fileUrl)

性能与结果控制 ​

  • getIsoBandsFast() 和 getIsoBandsFastByMask() 都在主线程生成等值带；大栅格或过密分级可能阻塞页面，应避免在拖动事件中反复调用。
  • getIsoBandsFastByMask() 会逐分级提取互斥面，透明显示更稳定，但计算量通常高于普通等值带。
  • clipDataByJson() 只把空间相交分发给 Worker，并不会把前面的等值带生成移出主线程。
  • Feature 数量和几何复杂度会直接影响 L.geoJSON() 的缩放、拖动和 setStyle() 更新性能；透明度与色标过滤都需要遍历现有矢量要素。
  • buildGridLineCanvas() 会按完整 nx × ny 规则格点绘制网格，首次生成大尺寸 Canvas 会占用额外主线程时间和内存。
  • 只需要连续栅格显示时，使用 GPU 栅格图层可以避免生成大量矢量多边形。

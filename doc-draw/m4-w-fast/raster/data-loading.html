数据加载 ​

本节由codex施工

所有加载入口最终返回同一种 RasterGrid。页面中的运行示例实际加载完整 MICAPS4 文件 2510270910.015；TIF 与参数方式保留在同一文件中，替换数据源时取消对应注释即可。

选择入口 ​

数据来源推荐入口适用情况
自动识别的数据源对象loadRasterGrid业务代码需要在 TIF、MICAPS4、参数数据之间切换
MICAPS4 URLloadMicaps4Grid已有可访问的 MICAPS4 文件地址
MICAPS4 文本parseMicaps4Text文本已经由上传控件、请求或其他方式读入内存
TIF URLloadTifGrid直接加载 TIF 的首个图像
参数对象createGridFromParams数值数组和网格范围已经在内存中

loadRasterGrid 的三种 source 写法如下。示例运行时只启用 MICAPS4，其余方式处于注释状态，便于直接替换。

RasterGrid ​

字段类型说明
valuesFloat32Array按规则网格排列的原始数值
width / heightnumber经度与纬度方向的格点数量
minLng / maxLngnumber经度范围
minLat / maxLatnumber纬度范围
stepLng / stepLatnumber相邻格点的经纬度间隔
noDatanumber无效值标记
valueScalenumber查询和渲染时应用的数值倍率

加载 API ​

API参数返回值说明
loadRasterGrid(source, options?)RasterSourcePromise<RasterGrid>根据 type 统一分发 TIF、MICAPS4 或 Params
loadMicaps4Grid(url, options?)stringPromise<RasterGrid>请求并解析 MICAPS4 文件
parseMicaps4Text(text, options?)stringRasterGrid直接解析 MICAPS4 文本
loadTifGrid(url, options?)stringPromise<RasterGrid>加载 TIF 的首个图像并转换
createGridFromParams(params, options?)RasterParamsRasterGrid从已有数组创建规则栅格
validateRasterGrid(grid)RasterGridRasterGrid校验尺寸、范围和数组长度，失败时抛出错误

RasterParams ​

参数类型必填说明
valuesArrayLike<number>是数值数组，长度应为 nx × ny
nx / nynumber是经度、纬度方向格点数
minLng / minLatnumber是网格起点
gjLng / gjLatnumber是经度、纬度间隔
noDatanumber否无效值标记
valueScalenumber否数值倍率
flipYboolean否是否反转纬度方向的数据行

RasterLoadOptions ​

flipY、noData 和 valueScale 可作为加载选项覆盖文件或参数中的默认值。调整 flipY 只改变数据行方向，不改变网格的经纬度范围。

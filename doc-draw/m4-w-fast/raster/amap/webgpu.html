高德 WebGPU ​

本节由codex施工

高德地图没有单独的包入口。本页使用 m4-w-fast/raster-rendering 的通用 WebGPU Renderer，把高德当前中心、缩放级别和容器尺寸转换为 EPSG:3857 视口，再把 GPU 结果合成到地图容器内的 Canvas。

运行示例 ​

示例加载真实 2510270910.015、完整色标和 620000.json 边界。拖动、缩放地图或连续调整控制条时，绘制请求采用 latest-wins：当前帧完成后只处理最新视口，避免堆积过期任务。

接入步骤 ​

  1. 用 RasterRenderState 保存数据、色标、过滤、透明度、采样和裁剪状态。
  2. 创建 WebgpuRasterRenderer，用离屏 Canvas 和 'epsg3857' 初始化。
  3. 根据高德地图的中心、缩放和容器尺寸计算 worldTopLeftX/Y。
  4. 调用 render(viewport)，再用 captureImageBitmap() 把当前结果复制到地图覆盖 Canvas。
  5. 监听地图移动、缩放和尺寸变化；销毁页面时解绑事件并调用 renderer.destroy()。

vue
<!-- 将通用 WebGPU 栅格渲染器接入高德地图视口并演示连续参数更新。 -->
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import AMapLoader from '@amap/amap-jsapi-loader'
import {
    normalizeColorStops,
    RasterRenderState,
    WebgpuRasterRenderer,
} from 'm4-w-fast/raster-rendering'
import type { RasterClipOptions } from 'm4-w-fast/raster-rendering'
import boundaryUrl from './data/620000.json?url'
import { loadRasterDemoGrid, rasterDemoColorStops } from './rasterLeafletDemoData'

const WEB_MERCATOR_TILE_SIZE = 256
const MAX_MERCATOR_LATITUDE = 85.0511287798

const mapElement = ref<HTMLDivElement | null>(null)
const opacity = ref(0.82)
const minValue = ref(-72)
const maxValue = ref(45)
const status = ref('正在初始化高德地图与 WebGPU')
const frameTime = ref<number | null>(null)

let map: AMap.Map | null = null
let renderer: WebgpuRasterRenderer | null = null
let overlayCanvas: HTMLCanvasElement | null = null
let renderCanvas: HTMLCanvasElement | null = null
let rendering = false
let renderRequested = false
let destroyed = false

const project = (longitude: number, latitude: number, zoom: number) => {
    const scale = WEB_MERCATOR_TILE_SIZE * 2 ** zoom
    const limitedLatitude = Math.max(-MAX_MERCATOR_LATITUDE, Math.min(MAX_MERCATOR_LATITUDE, latitude))
    const sinLatitude = Math.sin(limitedLatitude * Math.PI / 180)
    return {
        x: (longitude + 180) / 360 * scale,
        y: (0.5 - Math.log((1 + sinLatitude) / (1 - sinLatitude)) / (4 * Math.PI)) * scale,
    }
}

const renderSnapshot = async () => {
    if (!map || !renderer || !overlayCanvas || !renderCanvas || destroyed) return

    const startedAt = performance.now()
    const size = map.getSize()
    const cssWidth = size.getWidth()
    const cssHeight = size.getHeight()
    const ratio = window.devicePixelRatio || 1
    const canvasWidth = Math.max(1, Math.round(cssWidth * ratio))
    const canvasHeight = Math.max(1, Math.round(cssHeight * ratio))

    overlayCanvas.style.width = `${cssWidth}px`
    overlayCanvas.style.height = `${cssHeight}px`
    if (overlayCanvas.width !== canvasWidth) overlayCanvas.width = canvasWidth
    if (overlayCanvas.height !== canvasHeight) overlayCanvas.height = canvasHeight
    if (renderCanvas.width !== canvasWidth) renderCanvas.width = canvasWidth
    if (renderCanvas.height !== canvasHeight) renderCanvas.height = canvasHeight

    const center = map.getCenter()
    const zoom = map.getZoom()
    const centerWorld = project(center.getLng(), center.getLat(), zoom)
    renderer.render({
        canvasWidth,
        canvasHeight,
        cssWidth,
        cssHeight,
        devicePixelRatio: ratio,
        zoom,
        worldTopLeftX: centerWorld.x - cssWidth * 0.5,
        worldTopLeftY: centerWorld.y - cssHeight * 0.5,
    })

    const image = await renderer.captureImageBitmap()
    if (destroyed) {
        image.close()
        return
    }
    const context = overlayCanvas.getContext('2d')
    context?.clearRect(0, 0, canvasWidth, canvasHeight)
    context?.drawImage(image, 0, 0)
    image.close()
    frameTime.value = performance.now() - startedAt
}

const requestRender = async () => {
    if (rendering) {
        renderRequested = true
        return
    }

    rendering = true
    try {
        do {
            renderRequested = false
            await renderSnapshot()
            if (destroyed) break
        } while (renderRequested)
    } finally {
        rendering = false
    }
}

const handleMapChanged = () => void requestRender()

const initialize = async () => {
    if (!mapElement.value) return

    try {
        if (!navigator.gpu) throw new Error('当前浏览器不支持 WebGPU')
        window._AMapSecurityConfig = {
            securityJsCode: 'ceac2914fd39fca79ae9a9fb2b9a5975',
        }
        const [AMapRuntime, grid, boundaryResponse] = await Promise.all([
            AMapLoader.load({ key: '4404863bd6e3e1677e922cf75920078e', version: '2.0' }),
            loadRasterDemoGrid(),
            fetch(boundaryUrl),
        ])
        if (!boundaryResponse.ok) throw new Error(`620000.json 加载失败：${boundaryResponse.status}`)
        const boundary = await boundaryResponse.json() as RasterClipOptions['data']

        map = new AMapRuntime.Map(mapElement.value, {
            viewMode: '2D',
            center: [100.55, 37.65],
            zoom: 6.2,
            pitchEnable: false,
            rotateEnable: false,
            resizeEnable: true,
        })
        if (!map) return
        overlayCanvas = document.createElement('canvas')
        renderCanvas = document.createElement('canvas')
        overlayCanvas.className = 'amap-raster-overlay'
        overlayCanvas.style.position = 'absolute'
        overlayCanvas.style.inset = '0'
        overlayCanvas.style.zIndex = '120'
        overlayCanvas.style.pointerEvents = 'none'
        map.getContainer().appendChild(overlayCanvas)

        const state = new RasterRenderState()
        state.setGrid(grid)
        state.setColorStops(normalizeColorStops(rasterDemoColorStops))
        state.setColorRange({ minValue: minValue.value, maxValue: maxValue.value })
        state.setOpacity(opacity.value)
        state.setColorMode('step')
        state.setSampleMode('interpolate')
        state.setClip(boundary, 'direct')
        renderer = new WebgpuRasterRenderer(state)
        await renderer.initialize(renderCanvas, 'epsg3857')

        map.on('mapmove', handleMapChanged)
        map.on('moveend', handleMapChanged)
        map.on('zoomchange', handleMapChanged)
        map.on('resize', handleMapChanged)
        await requestRender()
        status.value = `${grid.width} × ${grid.height} 个真实格点 · 甘肃边界裁剪`
    } catch (error) {
        status.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

const updateOpacity = () => {
    renderer?.setOpacity(opacity.value)
    void requestRender()
}

const updateColorRange = (source: 'min' | 'max') => {
    if (minValue.value > maxValue.value) {
        if (source === 'min') maxValue.value = minValue.value
        else minValue.value = maxValue.value
    }
    renderer?.setColorRange({ minValue: minValue.value, maxValue: maxValue.value })
    void requestRender()
}

onMounted(() => void initialize())

onBeforeUnmount(() => {
    destroyed = true
    map?.off('mapmove', handleMapChanged)
    map?.off('moveend', handleMapChanged)
    map?.off('zoomchange', handleMapChanged)
    map?.off('resize', handleMapChanged)
    renderer?.destroy()
    overlayCanvas?.remove()
    map?.destroy()
    renderer = null
    map = null
})
</script>

<template>
    <section class="amap-demo">
        <div class="controls">
            <label>
                透明度 {{ opacity.toFixed(2) }}
                <input v-model.number="opacity" type="range" min="0" max="1" step="0.01" @input="updateOpacity">
            </label>
            <label>
                最小值 {{ minValue }}
                <input v-model.number="minValue" type="range" min="-72" max="45" step="1" @input="updateColorRange('min')">
            </label>
            <label>
                最大值 {{ maxValue }}
                <input v-model.number="maxValue" type="range" min="-72" max="45" step="1" @input="updateColorRange('max')">
            </label>
        </div>
        <div class="legend">
            <div class="legend-colors">
                <span
                    v-for="(stop, index) in rasterDemoColorStops"
                    :key="`${stop.min}-${stop.max}-${index}`"

            </div>
            <div class="legend-labels"><span>-72</span><span>分段色标</span><span>45+</span></div>
        </div>
        <div class="map-shell">
            <div ref="mapElement" class="map" />
            <div class="status">
                <span>{{ status }}</span>
                <strong>{{ frameTime === null ? '--' : `${frameTime.toFixed(1)} ms` }}</strong>
            </div>
        </div>
    </section>
</template>

RasterRenderState ​

方法参数说明
setGridRasterGrid设置或替换规则栅格
setColorStopsRasterColorStop[]设置已归一化色标
setColorRangeRasterColorRange | null设置显示值范围
setOpacitynumber设置栅格透明度
setColorMode'step' | 'smooth'设置颜色模式
setSampleMode'cell' | 'interpolate'设置采样模式
setClipPolygonMeshInput | null, ClipMode?设置 GeoJSON 裁剪数据和方式
setClipModeClipMode只切换现有裁剪数据的模式

WebgpuRasterRenderer ​

方法返回值说明
initialize(canvas, 'epsg3857')Promise<void>获取 Adapter/Device 并创建 GPU 资源
render(viewport)void按当前高德视口提交一帧
captureImageBitmap()Promise<ImageBitmap>取得当前画面快照，用于宿主 Canvas 合成
setGrid / setColorStopsvoid动态替换 GPU 数据或色标
setColorRange / setOpacityvoid连续更新显示范围或透明度
setColorMode / setSampleModevoid切换颜色与采样模式
setClip / setClipModevoid更新裁剪数据或模式
destroy()void释放 GPU 纹理、Buffer 和 Device 关联资源

接入边界 ​

  • 高德地图实例、Key、安全密钥、事件绑定和覆盖 Canvas 由业务侧管理。
  • 栅格经纬度使用 WGS84；如果业务要求与 GCJ-02 底图严格对齐，需要在数据或视口适配层处理坐标转换。
  • WebGPU 需要 localhost 或 HTTPS 安全上下文；地图和底图还需要网络连接。
  • 覆盖 Canvas 必须设置 pointer-events: none，否则会阻断地图拖动与缩放。

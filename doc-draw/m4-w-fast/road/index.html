道路 ​

本节由codex施工

道路模块把 LineString / MultiLineString GeoJSON 转成三角形 mesh，并在 Leaflet 地图上使用规则栅格值给每个路段着色。道路几何、栅格采样和色标状态由公共数据层管理，WebGL2 与 WebGPU 只负责各自的 GPU 资源和绘制过程。

数据流 ​

  1. 读取道路 GeoJSON 和规则栅格。
  2. parseRoadGeoJson() 规范化 LineString / MultiLineString。
  3. buildRoadMesh() 把相邻坐标转换为 GPU 三角形。
  4. 渲染器在道路顶点对应坐标处采样栅格。
  5. 根据 colorStops、colorRange 和 colorMode 输出道路颜色。

真实数据 ​

道路页面统一使用兰州区域的真实 highway GeoJSON，共 5,152 个线要素、48,068 个坐标点；栅格使用真实 MICAPS4 文件 2510270910.015，裁剪使用真实行政区边界 620000.json。

入口 ​

ts
import {
    buildRoadMesh,
    createRoadLeafletLayer,
    parseRoadGeoJson,
    prepareRoadData,
} from 'm4-w-fast/road-overlay'

Leaflet 成品图层通常直接使用 createRoadLeafletLayer()。只有需要在创建图层前检查道路数量、边界或 mesh 规模时，才单独调用前三个数据 API。

裁剪与动态控制 ​

本节由codex施工

道路图层可以在创建时传入 Polygon / MultiPolygon 边界，并在不重建 mesh 和栅格纹理的情况下切换裁剪模式、透明度、线宽、颜色模式和采样模式。

运行示例 ​

示例使用真实 highway GeoJSON 和 2510270910.015。红框是道路范围内部的一块小矩形，地图仍显示完整道路范围，便于直接比较框内、框外的裁剪结果。

关键代码 ​

vue
<!-- 使用小矩形范围展示真实道路的裁剪和动态参数控制。 -->
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import * as L from 'leaflet'
import 'leaflet/dist/leaflet.css'
import type { FeatureCollection, GeoJsonObject, Polygon } from 'geojson'
import { createRoadLeafletLayer } from 'm4-w-fast/road-overlay'
import type { RoadLeafletLayer } from 'm4-w-fast/road-overlay'
import {
    loadRasterDemoGrid,
    loadRoadDemoData,
    rasterDemoColorStops,
    roadDemoBounds,
} from './roadLeafletDemoData'

type ClipMode = 'none' | 'direct' | 'stencil' | 'mask'

const clipBoundary: FeatureCollection<Polygon> = {
    type: 'FeatureCollection',
    features: [{
        type: 'Feature',
        properties: {
            name: '道路裁剪范围',
        },
        geometry: {
            type: 'Polygon',
            coordinates: [[
                [103.69, 35.91],
                [103.81, 35.91],
                [103.81, 36.03],
                [103.69, 36.03],
                [103.69, 35.91],
            ]],
        },
    }],
}

const mapElement = ref<HTMLDivElement | null>(null)
const status = ref('等待初始化')
const clipMode = ref<ClipMode>('direct')
const opacity = ref(0.95)
const lineWidth = ref(6)

let map: L.Map | null = null
let roadLayer: RoadLeafletLayer | null = null
let resizeObserver: ResizeObserver | null = null

const readControlValue = (event: Event): string => {
    return (event.target as HTMLInputElement | HTMLSelectElement).value
}

const updateClipMode = (event: Event) => {
    const value = readControlValue(event) as ClipMode
    clipMode.value = value
    roadLayer?.setClipMode(value)
}

const updateOpacity = (event: Event) => {
    const value = Number(readControlValue(event))
    opacity.value = value
    roadLayer?.setOpacity(value)
}

const updateLineWidth = (event: Event) => {
    const value = Number(readControlValue(event))
    lineWidth.value = value
    roadLayer?.setLineWidth(value)
}

const initialize = async () => {
    if (!mapElement.value) return

    try {
        status.value = '正在加载真实道路和栅格数据'
        const [roads, grid] = await Promise.all([
            loadRoadDemoData(),
            loadRasterDemoGrid(),
        ])

        map = L.map(mapElement.value, {
            center: [35.97, 103.75],
            zoom: 10,
        })
        L.tileLayer('https://webrd0{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}', {
            subdomains: ['1', '2', '3', '4'],
            maxZoom: 18,
        }).addTo(map)
        map.createPane('road-clip-pane')
        const pane = map.getPane('road-clip-pane')
        if (pane) pane.style.zIndex = '420'

        L.geoJSON(clipBoundary as GeoJsonObject, {
            style: {
                color: '#ff2d55',
                weight: 1.5,
                fill: false,
            },
            interactive: false,
        }).addTo(map)

        roadLayer = await createRoadLeafletLayer({
            rendererType: 'webgl2',
            roads,
            grid,
            colorStops: rasterDemoColorStops,
            colorRange: {
                minValue: -8,
                maxValue: 8,
            },
            colorMode: 'step',
            sampleMode: 'interpolate',
            opacity: opacity.value,
            lineWidth: lineWidth.value,
            pane: 'road-clip-pane',
            clip: {
                data: clipBoundary,
                mode: clipMode.value,
            },
        })
        roadLayer.addTo(map)
        map.fitBounds(roadDemoBounds, { padding: [20, 20] })

        resizeObserver = new ResizeObserver(() => map?.invalidateSize())
        resizeObserver.observe(mapElement.value)
        status.value = '红框为裁剪范围，框外道路用于观察不同裁剪模式'
    } catch (error) {
        status.value = error instanceof Error ? error.message : '示例初始化失败'
    }
}

onMounted(() => void initialize())

onBeforeUnmount(() => {
    resizeObserver?.disconnect()
    resizeObserver = null
    map?.remove()
    roadLayer = null
    map = null
})
</script>

<template>
    <section class="clip-demo">
        <header>
            <h3>道路裁剪与动态控制</h3>
            <p>{{ status }}</p>
        </header>

        <div class="controls">
            <label>
                <span>裁剪模式</span>
                <select :value="clipMode" @change="updateClipMode">
                    <option value="none">不裁剪</option>
                    <option value="direct">直接裁剪</option>
                    <option value="stencil">模板裁剪</option>
                    <option value="mask">遮罩裁剪</option>
                </select>
            </label>
            <label>
                <span>透明度 {{ opacity.toFixed(2) }}</span>
                <input :value="opacity" type="range" min="0" max="1" step="0.01" @input="updateOpacity">
            </label>
            <label>
                <span>线宽 {{ lineWidth.toFixed(1) }}px</span>
                <input :value="lineWidth" type="range" min="1" max="16" step="0.5" @input="updateLineWidth">
            </label>
        </div>

        <div class="legend">
            <span
                v-for="stop in rasterDemoColorStops.slice(16, 23)"
                :key="`${stop.min}-${stop.max}`"
                :style="{ backgroundColor: stop.color }"
                :title="`${stop.min} ～ ${stop.max}`"
            />
        </div>

        <div ref="mapElement" class="map" />
    </section>
</template>

CoverageOptions ​

参数类型默认值必填说明
dataPolygonMeshInput-是Polygon、MultiPolygon、Feature 或 FeatureCollection
mode'none' | 'direct' | 'stencil' | 'mask''direct'否初始裁剪模式

裁剪模式 ​

模式处理方式说明
none不使用边界临时查看完整道路
direct使用边界 mesh 参与绘制默认模式
stencil先写模板缓冲，再绘制道路通过模板测试限制区域
mask生成覆盖纹理并在着色时采样通过纹理遮罩限制区域

动态方法 ​

方法是否重建图层说明
setClipMode(mode)否复用创建时的边界
setOpacity(opacity)否更新 0 到 1 的透明度
setLineWidth(lineWidth)否更新 CSS 像素线宽
setColorMode(mode)否切换 step / smooth
setSampleMode(mode)否切换 interpolate / cell
redraw()否手动请求当前视口重绘

当前 RoadLeafletLayer 没有公开 setClip()、setGrid()、setColorStops() 或 setColorRange()。需要替换这些数据时应移除旧图层并重新调用 createRoadLeafletLayer()。

注意事项 ​

  • 裁剪输入必须是面几何，LineString 不能作为边界。
  • 边界坐标必须与道路显示坐标一致；使用 GCJ-02 底图时应统一考虑坐标转换。
  • setClipMode() 只切换渲染路径，不重新读取 GeoJSON 或 MICAPS4 文件。

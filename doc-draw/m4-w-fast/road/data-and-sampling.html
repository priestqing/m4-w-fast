GeoJSON 与栅格采样 ​

本节由codex施工

道路颜色不是来自 GeoJSON 属性，而是从规则栅格中按道路坐标采样。显示坐标负责把道路画到地图上，采样坐标负责决定从栅格的哪个位置读取数值。

数据加载 ​

页面运行时读取筛选后的真实 highway GeoJSON，并复用栅格文档中的 MICAPS4 加载函数。

ts
// 提供道路文档使用的真实 highway GeoJSON、行政区边界和栅格数据。
import type { FeatureCollection, MultiPolygon, Polygon } from 'geojson'
import type { RoadGeoJsonInput } from 'm4-w-fast/road-overlay'
import roadGeoJsonUrl from './data/road-highways.json?url'
import boundaryGeoJsonUrl from '../raster/data/620000.json?url'
import {
    loadRasterDemoGrid,
    rasterDemoColorStops,
} from '../raster/rasterLeafletDemoData'

export const roadDemoBounds: [[number, number], [number, number]] = [
    [35.8304181, 103.6126398],
    [36.1099785, 103.9042068],
]

const loadJson = async <T>(url: string, label: string): Promise<T> => {
    const response = await fetch(url)
    if (!response.ok) throw new Error(`${label} 加载失败：${response.status}`)
    return await response.json() as T
}

export const loadRoadDemoData = (): Promise<RoadGeoJsonInput> => {
    return loadJson<RoadGeoJsonInput>(roadGeoJsonUrl, '道路 GeoJSON')
}

export const loadRoadBoundary = (): Promise<FeatureCollection<Polygon | MultiPolygon>> => {
    return loadJson<FeatureCollection<Polygon | MultiPolygon>>(boundaryGeoJsonUrl, '行政区边界')
}

export {
    loadRasterDemoGrid,
    rasterDemoColorStops,
}

道路输入只接受 LineString 和 MultiLineString。包含其他几何类型的 FeatureCollection 应先筛选，再传给道路 API。

数据处理 API ​

API参数返回值说明
parseRoadGeoJsonroads, coordinateTransform?, sampleCoordinateMode?RoadGeometryParseResult规范化道路、拆分 MultiLineString、计算边界
buildRoadMeshRoadGeometry[]RoadMesh把道路相邻点转换为三角形 mesh
prepareRoadDataroads, coordinateTransform?, sampleCoordinateMode?PreparedRoadData一次完成解析与 mesh 构建
normalizeRoadLayerOptionsRoadLayerCreateOptionsNormalizedRoadLayerOptions校验创建参数并补齐默认值

坐标转换 ​

coordinateTransform显示坐标采样坐标适用情况
'none'保持输入坐标由 sampleCoordinateMode 决定OSM 等 WGS84 / Web Mercator 底图
'wgs84-to-gcj02'WGS84 转 GCJ-02可保留 WGS84高德底图与 WGS84 栅格组合

采样坐标模式 ​

sampleCoordinateModesampleX/sampleY 来源说明
'source'转换前坐标默认值；底图需要坐标偏移、栅格仍是源坐标时使用
'display'转换后坐标栅格和底图都使用显示坐标时使用

RoadCoordinate.x/y 用于绘制，sampleX/sampleY 用于读取栅格。两套坐标分开保存，避免为了对齐底图而把采样位置一起偏移。

RoadGeometryParseResult ​

字段类型说明
roadsRoadGeometry[]规范化后的单条道路集合
boundsRoadBounds | null全部道路范围
pointCountnumber道路坐标点总数
lineCountnumber规范化后的线数量

RoadMesh ​

字段类型说明
verticesFloat32ArrayGPU 顶点数据
segmentsRoadMeshSegment[]原道路索引与顶点区间
vertexCountnumber顶点数
triangleCountnumber三角形数
layoutRoadMeshVertexLayout9 个 float 的顶点布局

每个路段使用两个三角形。顶点同时保存显示坐标、路段起止点、采样坐标和局部顶点索引，线宽由 GPU 根据当前视口展开。

栅格输入 ​

createRoadLeafletLayer() 的 grid 和 source 必须二选一：

参数类型说明
gridRasterGrid已经加载完成，可与其他图层共享
sourceRasterSource在创建道路图层时加载 TIF、MICAPS4 或参数数据

多个图层使用同一份数据时优先预加载 grid，避免重复请求和解析。

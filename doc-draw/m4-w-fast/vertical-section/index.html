垂直剖面 ​

本节由codex施工

垂直剖面模块把三维规则体数据统一为 IVolumeSource，再按路线生成二维剖面、三维墙体纹理或体积场景中的路线面。数据解析、水平层适配、路线采样和统计均由 m4-w-fast 完成，显示端只消费公共结果。

数据链 ​

  1. loadVolumeSource 按明确格式解析 ZIP，产出带分块读取能力的 IVolumeSource。
  2. createHorizontalRasterGrid 读取指定时间和高度，生成北向第一行、西向第一列的 RasterGrid。
  3. createVolumeSection 沿路线按格点或双线性插值采样，生成二维剖面。
  4. 二维结果可转为 RasterGrid 或路线面；原始 IVolumeSource 可直接交给独立 WebGPU 场景或 Mars3D 的 Cesium 原生体积图层。

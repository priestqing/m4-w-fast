m4-w-fast ​

本节由codex施工

m4-w-fast 用于处理和绘制气象规则网格、道路以及三维体数据。包内的数据解析、采样、色标、裁剪和查询能力与地图框架分离，同一份数据可以按需要接入 Leaflet、高德地图、Mars3D 或独立 WebGPU 场景。

文档分类 ​

分类主要内容文档
栅格TIF、MICAPS4、参数数据、GeoJSON、色标、查询、裁剪以及多地图渲染栅格
道路道路 GeoJSON、栅格采样、道路 mesh、WebGL2/WebGPU 渲染和裁剪控制道路
垂直剖面体数据 ZIP、水平层、路线剖面、三维剖面墙、体积与轴切片垂直剖面

各分类概览负责列出已完成和等待施工的细分能力，具体页面只讲当前功能的加载、处理、输出和 API。

安装 ​

bash
npm install m4-w-fast

按功能从子路径导入，不需要一次加载整个包：

ts
import { createRasterLeafletLayer } from 'm4-w-fast/raster-leaflet'
import { createRoadLeafletLayer } from 'm4-w-fast/road-overlay'
import { createVolumeSection } from 'm4-w-fast/volume-section'

公共数据 ​

数据说明
RasterGrid规则经纬度网格，包含宽高、范围、数值和缺测值约定
RoadGeoJsonInputLineString / MultiLineString 道路数据
IVolumeSource支持按时间和空间分块读取的三维规则体数据源
IVolumeSection沿指定路线采样得到的距离 × 高度二维剖面

栅格、道路和剖面共用同一套色标与采样语义：

  • step 使用分段颜色，smooth 在相邻色标之间连续插值。
  • cell 读取所在格点，interpolate 使用双线性插值。
  • colorRange 负责数值过滤，opacity 负责整体透明度。
  • 经纬度数据统一使用 WGS84；接入其他坐标系底图时由业务侧处理坐标转换。
